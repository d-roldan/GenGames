# Privacidad infantil

Sólo se genera un UUID aleatorio local. No se recopilan nombre, edad, ubicación,
contactos, fotos, cámara, micrófono ni identificadores publicitarios. No existen
publicidad, chat, redes sociales ni enlaces infantiles. La metadata de eventos
se valida y se limita. El área adulta está separada mediante gesto prolongado y
desafío.
