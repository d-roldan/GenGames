# Aplicación móvil

Flutter comparte UI y lógica en Windows y Android. Los entrypoints/flavors inyectan
entorno y URL; no contienen secretos. Juegos se registran mediante `GameDefinition`.
SQLite conserva instalación, preferencias, estadísticas y cola. El panel adulto
requiere pulsación prolongada y desafío, y muestra uso, volumen, contenido y versión.
